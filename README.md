# Основы Python: практические работы

Сборник задач, которые я решал во время изучения Python (2024). Репозиторий показывает путь от первых программ с `input()` и `print()` до работы с матрицами, функциями и классами.

## Темы

| Папка | Тема | Что внутри |
|---|---|---|
| [`01_basics`](01_basics) | Основы | переменные и типы, логические операторы, срезы строк и списков, вычисления по формулам |
| [`02_conditions`](02_conditions) | Условия | `if` / `elif` / `else`, максимум и минимум, существование треугольника, високосный год, мини-игра с загадками |
| [`03_lists`](03_lists) | Списки и циклы | `remove`, `insert`, `sort`, генераторы списков, циклы `for` и `while`, обработка ошибок через `try` / `except` |
| [`04_matrices`](04_matrices) | Матрицы | двумерные списки, поиск минимума и максимума, суммы и произведения по условию, статистика по строкам |
| [`05_functions`](05_functions) | Функции | `def`, параметры, `return`, `if __name__ == "__main__"` |
| [`06_oop`](06_oop) | ООП | класс `Tourist` с методом вывода, задачи на вычисления и обработку массивов |

## Что я отработал

- ввод данных и преобразование типов (`int`, `float`, `str`);
- ветвления и логические выражения;
- циклы и работу со списками, включая генераторы списков;
- двумерные массивы (матрицы) и алгоритмы поиска по ним;
- функции и повторное использование кода;
- обработку ошибок ввода;
- основы объектно-ориентированного программирования.

## Как запустить

Нужен Python 3.8 или новее, сторонние библиотеки не используются.

```bash
git clone https://github.com/pride123/classworked.git
cd classworked
python 05_functions/leap_year.py
```

Большинство программ интерактивные: они спрашивают данные через консоль.
